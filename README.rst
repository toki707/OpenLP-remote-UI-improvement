Overview
--------

A modernized, church-focused UI upgrade for **OpenLP 3.1.7**, designed to make
remote control from a smartphone self-sufficient and simplify the desktop
interface for youth and new volunteers.

Key Features
------------

1. Redesigned Mobile Web Remote
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

* **Dual Preview & Live Monitors**: Preview any verse, image, custom slide, or
  service item on your phone before sending it to the projector with a single
  **Go Live** tap.
* **Direct Mobile Gallery Image Upload**: Pick announcements, weekly schedules,
  or posters directly from your phone's photo gallery and preview or project
  them immediately without touching the PC.
* **Streamlined Collapsible Drawer**: Focused navigation containing only the
  essential sections:

  * **Services**: Manage and trigger service items with 1-tap *Preview* or *Live*.
  * **Images**: Upload from mobile gallery or browse the OpenLP image library with thumbnails.
  * **Bible**: Fast *Book → Chapter → Verse* selector + search with full verse text preview before projection.
  * **Themes**: Browse OpenLP visual themes with live thumbnails and switch formatting in one tap.
  * **Custom Slides**: Create or edit sermon titles (*Theme of the Word*) and text announcements directly from your phone.

* **Original 5 Bottom Controls Preserved**: *Previous Item*, *Next Item*,
  *Previous Slide*, *Next Slide*, and *Display Mode* (*Blank / Theme / Desktop / Show*).
* **Dark & Light Mode**: Instant toggle between high-contrast Dark and Light themes.

2. Simplified Desktop UI ("Youth Mode")
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

* **Quick-Access Top Toolbar**: 1-click access to **Bible**, **Images**,
  **Custom Slides**, and **Songs**.
* **Simplified Mode Toggle**: Hides complex/unused panels for beginners while
  **keeping the direct "Go Live" button** inside every tab.
* **Live Dark / Light Theme Switcher**: Switch the desktop interface between
  Dark and Light themes in one click.

Quick Installation (Windows)
----------------------------

1. Download **``OpenLP-Remote-UI-Setup.exe``** from the
   `Releases <https://github.com/toki707/OpenLP-remote-UI-improvement/releases>`_ page.
2. Double-click **``OpenLP-Remote-UI-Setup.exe``** and click
   **"Installer et Lancer OpenLP"** (or run ``install_custom_ui.bat``).
